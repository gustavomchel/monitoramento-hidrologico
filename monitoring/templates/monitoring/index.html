O projeto

Uma solução de demonstração para um desafio real de desenvolvimento.

O desafio proposto pela COGMO foi adaptado para Python + Django. A aplicação representa estações hidrológicas fictícias e disponibiliza observações sintéticas, permitindo exercitar modelagem de dados, persistência, desenvolvimento de serviços REST e documentação de API.

Estações

Cadastro lógico de estações com identificação, nome, rio e município.

Séries históricas

Consulta de observações de nível da água (m) e intensidade de chuva (mm/h), com janela de tempo configurável.

Dados sintéticos

Dados gerados para demonstração e testes, sem representar medições de rios reais.

API REST

A API conecta os dados à aplicação.

A API é a camada que permite consultar estações e suas observações de forma estruturada. Ela separa o acesso aos dados das regras de apresentação e pode ser consumida por interfaces ou outras aplicações. Esta página institucional é a porta de entrada do sistema; a documentação interativa continua sendo oferecida pelo drf-spectacular.

O que pode ser consultado?

Os recursos abaixo são disponibilizados pela API sob o prefixo /api/.

GET/api/stations
Lista as estações disponíveis.
GET/api/stations/{id}
Retorna os dados de uma estação.
GET/api/stations/{id}/summary
Apresenta as leituras mais recentes de nível e chuva.
GET/api/stations/{id}/series?metric=level&hours=24
Consulta a série histórica por métrica e período (1 a 72 horas).
